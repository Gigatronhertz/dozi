The DOZI mark as inline SVG — use wherever the brand appears (header, footer, hero, tags). Never retype "DOZI" in a font in place of the mark.
```jsx
<Logo variant="wordmark" width={96} />
<Logo variant="lockup" width={220} color="var(--bone-100)" />
<Logo variant="symbol" width={24} color="var(--brass)" />
```
Colours: ink, bone, oxide, forest, brass only. Minimum wordmark width 64px; symbol 16px.
