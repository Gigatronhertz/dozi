Primary action control — square corners, uppercase tracked label. One primary per view.
```jsx
<Button>Add to bag</Button>
<Button variant="secondary">Design it</Button>
<Button variant="inverse" size="lg">Explore the design</Button>
```
Use inverse on photography/ink grounds. Hover fills secondary with ink.

On denim: `variant="patch"` (stitched bone, primary) and `variant="thread"` (dashed thread outline, secondary).
