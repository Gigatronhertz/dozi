# DOZI website UI kit
Proposed redesign of https://dozi-eight.vercel.app/ built on this design system, using the live site's copy.
Screens: Home, Shop, Product (with modular add-ons), Studio (4-step configurator), Bag drawer. Open `index.html`; nav persists across reloads.
Components are loaded from `/components` by `loader.js` (no build). Campaign photos hot-link the live site; packshots/details are cropped from the brand boards in `/assets/img`.
